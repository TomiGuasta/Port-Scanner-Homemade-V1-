# Assets

Esta carpeta contiene capturas y evidencia visual del funcionamiento del proyecto en distintos escenarios de ejecución y pruebas de laboratorio.

## Modos de Escaneo

Incluye ejemplos de ejecución y resultados obtenidos utilizando:

- **Fast Scan**
- **Intermediate Scan**
- **Full Scan**

## Modos de Comportamiento

Capturas correspondientes a los diferentes perfiles de ejecución del scanner:

- **Stealth Mode**
- **Audit Mode**
- **Aggressive Mode**

## Reportes y Validación

También se incluyen:

- Generación de **reportes HTML**
- Resultados de pruebas realizadas sobre **Metasploitable 2**
- Comparativas entre distintos modos de ejecución

Las capturas fueron obtenidas en un entorno local y controlado de laboratorio, con el objetivo de validar el comportamiento, rendimiento y diferencias entre los distintos perfiles del scanner.
